# NeuroNap

NeuroNap is a Python-based sleep tracking and sleep quality prediction application designed to help users monitor sleep patterns, calculate sleep debt, and predict sleep quality using machine learning.

## Features

- Sleep tracking
- Sleep debt calculation
- Sleep quality prediction
- SQLite database integration
- Tkinter graphical user interface
- Machine learning analysis using scikit-learn

## Technologies Used

- Python
- Tkinter
- SQLite
- scikit-learn
- pandas
- NumPy

## Why This Project Matters

Sleep plays an important role in physical health, mental well-being, and productivity. NeuroNap was developed to provide users with data-driven insights that encourage healthier sleep habits and better lifestyle decisions.
